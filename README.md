# Digital Clock

A simple digital clock web application that displays the current time and date.

## Features

- Displays current time in 12-hour format with AM/PM
- Shows the current date including day, month, date, and year
- Updates every second automatically

## How to Run

1. Open `index.html` in a web browser.
2. The clock will start displaying the current time and date.

## Technologies Used

- HTML
- CSS
- JavaScript
